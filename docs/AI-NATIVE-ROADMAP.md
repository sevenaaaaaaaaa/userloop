# UserLoop · AI Native 路线（双视角：使用者 / 终端用户）

> 本质：UserLoop 是 MA（Marketing Automation）工具。传统 MA = 人写规则 → 固定动作 → 报表；
> AI Native MA = **目标驱动 → AI 规划 → 执行 → 自评 → 迭代**，人从"配置者"变为"目标与边界设定者"。
> 本文按两个视角盘点差距与机会，并标注现状与优先级。

## 一、能力现状（已交付）

事件总线 / 自有 CDP-lite（8 阶段旅程 + 断点）/ Loop 引擎（模板 + 验证回流）/ Canvas 图执行 /
AI 大脑（NBA 决策 + 频控/静默期/预算 + 风险审批门）/ 触点（邮件 HTML+追踪+退订+抑制、短信三供应商、
H5 双引擎 + 六维千面、IM、HubSpot、OpenFlow/MFlow 互通）/ A/B 版式实验（显著性 + 提升）/
身份图谱 / 验收入口（控制台、A-B、AI 决策、MCP 只读回读）。

## 四、AI Native 范式差异（本质层面）

| 维度 | 传统 MA | AI Native MA | UserLoop 位置 |
|---|---|---|---|
| 起点 | 人写规则 | 人给目标 + 边界 | 模板为主，AI 大脑已能决策 |
| 编排 | 手工画布 | **自然语言生成 + 人审** | A1 本轮补上 |
| 内容 | 人写文案 | **AI 生成 + 质检门 + A/B 自提升** | 有 AI 文案 + A/B 提升，缺质检门（A4 本轮补） |
| 优化 | 人看报表调参 | **自评 → 自动迭代** | 有验证回流，缺自动改流程 |
| 预测 | 无 | churn / LTV / 购买倾向 | ✅ 规则 v1 + **模型 v2 管线就绪**（回放式训练/自适应窗口/融合/自动回退，随数据积累自动生效） |
| 时机 | 固定时间 | **STO + 个体最优时机** | 仅静默期 |
| 触达形态 | 群发 | **对话 + 个体连续性** | 单向为主 |

## 五、路线图（按投入产出排序）

- **P0（已完成）**：A1 Copilot 自然语言建流程；A4 发前质检门
- **P1（全部完成）**：跨渠道全局频控、Next Best Channel、AI 周报 + 批量审批、**STO 发送时机优化**、
  **合规中心（consent + DSAR）**、**自然语言分群**
- **已完成的基础层**：**识别（匿名→实名合并 + 归并连续性）**、**预测（churn/LTV/propensity 可解释评分）**
- **P2（已完成两项）**：
  - ✅ **预测模型化**：回放式特征工程（参考时点 T 前算特征、(T, now] 定标签）+ 纯 Python 逻辑回归、
    样本自适应融合（`blend` 权重随样本量增长，上限 0.7）、样本不足**自动回退规则**并说明原因；
    每日自动重训。**实测**：线上历史仅 15.3 天且绝大多数事件在近 2 天 → 当前合格样本 1 条 → 回退规则
    （这是诚实的结果：数据到位后自动激活，无需人工干预）
  - ✅ **智能分群 UI**：控制台「智能分群」面板（一句话 → 规则 → 命中预览/样例 → 保存 → 导出 CSV → 一键 AI 决策）
- **P2（待做）**：对话式触达（微信/WhatsApp AI 跟进，需外部凭据）、多租户 / i18n
- **P2**：预测层（churn/LTV 评分 → 驱动 AI 大脑与分群）、B6 对话式触达、A8 多租户/i18n

## 六、识别与预测（本轮补齐的基础层）

- **识别**：`identities` 身份图谱 + **匿名→实名合并**（`merge_users` 跨表迁移：事件/身份/台账/分数/决策），
  合并后同匿名来源事件持续归并；H5 留资表单 + `POST /api/v1/identify` + `track.js` 的 `userloop.identify()`；
  识别率可观测（线上当前 3.5%，是最大数据质量瓶颈）
- **预测**：`user_scores(churn/ltv/propensity/tier/best_hour + reasons)`，每小时批量重算；
  已注入 AI 大脑决策上下文与周报；控制台「预测洞察」面板可看高风险/高价值名单并一键触发 AI 决策

## 七、判断标准（为什么这么排序）

1. **先解决"人怎么用"**：MA 工具失败的主因不是缺功能，而是运营不会配、配错、配了不放心 → Copilot + 质检门
2. **再解决"用户体验"**：跨渠道骚扰是 MA 最大的隐性成本（退订/投诉/品牌损伤）→ 全局频控 + 渠道选择
3. **最后做预测/对话**：需要数据积累（我们已有事件量与回流数据），且需外部凭据（微信/WhatsApp）
